NeonyReactive desktop UI in pure Python

Compose desktop interfaces from Python objects — components, layouts, styles — rendered in a native window and diff-updated automatically. No HTML, no JavaScript. (pre-beta)

Get Started
View on GitHub

Pure Python API

Components, layouts and events are plain Python objects — application code never writes HTML or JavaScript.

Fine-grained reactivity

Signal / Computed / Effect primitives with declarative bindings; dirty-subtree diffing updates only what changed.

Same stack as Tauri

Rust tao/wry WebViews via LumiView; custom window chrome, transparency and native window effects.

Bilingual docs

Complete documentation in English and 中文, with built-in search and version history.
